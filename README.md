# GAMJAS 🥔 여행 플랫폼

> **6/9 ~ 7/9** 팀 프로젝트 종료  
> **7/16 ~** 개인 리빌드 진행 중

**GAMJAS**는 지하철 노선도 + 구글 지도 API를 기반으로  
사용자에게 **여행 정보**와 **미션 투어 기능**을 제공하는 웹 플랫폼입니다.

---

## ✨ 주요 기능

- 📍 **지하철 노선도 시각화** (Google Maps 기반)
- 🔍 **여행 정보 장소 조회** (축제, 명소, 맛집 등)
- 🚇 **지하철역 반경 기반 장소 추천**
- 🎯 **미션 수행 → 감자 티켓 지급 → 경품 응모**
- 📝 **커뮤니티 및 후기 작성 기능**

## 📌 프로젝트 개요

- **주제:** 여행자 맞춤형 플랫폼
- **포인트:** 지하철 중심의 위치 기반 정보 제공
- **기획 목표:** 정보 제공을 넘어 관광객 간 소통과 참여가 이루어지는 플랫폼
- **역할:** 커뮤니티 게시판, 파일 첨부, 댓글 기능, 관리자 페이지 등 구현
